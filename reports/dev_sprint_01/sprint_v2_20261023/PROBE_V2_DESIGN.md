# Probe v2 design — written before generation and inference

ASSUMED design, 23 October 2026 (Asia/Calcutta). This is a new single-author synthetic diagnostic, not a field baseline. V1 remains frozen and evaluation-only. No model scores enter generation. Labels reflect authored intent and remain PROVISIONAL pending user review.

600 Hinglish MALICIOUS: 12 original attack families × 50. 400 BENIGN: 33 scenario contrasts per family plus four safe OTP/transactional notices. 100 SPAM: promotion with no secret request. Random English translations of exactly 25% of each class: 150/100/25. Eight persona batches: terse service, formal desk, friend, student, hurried texter, household, merchant, colloquial adviser. No generic length padding. Target mostly 6–30 words. 50/50 SMS/WhatsApp across Hinglish classes; sender metadata is never used. 40% URL-less per attack family (half callback, half reply-only); URL forms https://neutral-label.invalid/random-path contain no family names. Contiguous phone tokens 9000000NNN are invented diagnostic patterns, not verified unassigned telephone numbers; never dial/fetch/resolve. No real payloads.

Generation uses author-written attack demands and safe contrasts, varied scenario anchors, eight short voices, and five spelling levels. Demand must be explicit (secret disclosure, fraudulent payment, coerced remote access/installation), not only a quoted warning. Benign twins are informed self-service/transactional or retrospective/negated requests. Label QA is author review plus a random user sample; no claim of independent adjudication. Near-identical cap: normalized exact and token-Jaccard >= .85 connected components no larger than 3; generation may reject excess neighbors BEFORE scores and must disclose rejection counts. Shared grammar remains correlated despite this cap.

Random user review: 60 malicious, 40 benign, 20 spam, sampled within class without enrichment, fixed seed 202610231. Do not silently relabel or overwrite. If >5% of reviewed rows are wrong, create a new numbered set before trusting v2. Confidence intervals: Wilson 95%, row-level and descriptive; N<30 indicative only. Also show all / no lexical-overlap rows. No fitting, model selection, or gate tuning on either probe.

V1 diagnostics: original text; normalized URLs/phones only (same labels); original rows where the prior blind classifier accepted active intent. The latter is selection-biased and cannot be treated as recall on all attacks. User-disputed rows are reported separately and excluded only in a separately named corrected analysis. Report marked-count and exclusion definition.

Unchanged PROPOSED verdict rules: false positives main if attack-recall lower95 >=.90 AND no family with N>=30 point recall <.80 AND paired English-minus-Hinglish gap <=5 points. Recall also problem if overall point <.85 OR >=3 families point <.80 OR paired English gap >10 points. Otherwise mixed/inconclusive. Do not reinterpret as a real-world accuracy estimate. Continue to feature ledger regardless of verdict.

Frozen bundles: V2 tau .704, V4.3 tau .61, six V4.4 original configured thresholds. Alert only if final thresholded predicted class MALICIOUS. Save all three probabilities. Reconfirm V4.3 TEST 1510/1556 malicious correct and 2/520 benign any-nonbenign before probe scores. Source TEST contains non-English metadata; separately report English subset and full historic target.

Freeze commitment is a separate immutable freeze_manifest.json written after score-free audit and before inference. It hashes this design and the final CSV; no circular self-hash. The generator and all outputs use exclusive creation. Progress is saved in new per-stage directories to reconcile progress updates with the prohibition on overwriting existing files.
