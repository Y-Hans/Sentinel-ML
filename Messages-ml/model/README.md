# Model Artifacts Directory

This directory is reserved for validated model artifacts generated by the Message ML training and export pipeline:
- `model.tflite` (Quantized on-device model)
- `scaler.json` (Mean/scale standardization parameters)
- `feature_config.json` (Active feature group definitions and ordering)
- `rules_config.json` (Deterministic rule regex configurations)
- `labels_mapping.json` (Taxonomy index mappings)
- `metadata.json` (Experiment metadata, input/output tensors, slice metrics)

> **Notice**: Production model artifacts will be populated following empirical model selection on approved datasets.
